# My Website Deployment (Docker + AWS EC2)

## 🚀 Project Overview
This project is a static website deployed using Docker on AWS EC2 (Linux server).

## 🛠️ Technologies Used
- HTML, CSS
- Docker
- AWS EC2 (Ubuntu Linux)
- Git & GitHub

## ⚙️ Steps Performed
1. Created a static website
2. Dockerized the application using Nginx
3. Deployed container on AWS EC2
4. Configured security groups
5. Connected via SSH and ran Docker container
6. Made website live on public IP
